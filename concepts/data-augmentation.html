資料增強

Data Augmentation

一句話定義

訓練時把每張圖隨機翻轉、裁切、調亮調暗再給模型看，讓它學會「這些變化不影響答案」。

直覺理解

準備考試時，同一題換個數字、換個問法多練幾次，比把原題背起來更有用。考試時題目稍微改一下，你還是會寫。

模型只看過「貓臉朝左、光線充足」的照片，遇到朝右或偏暗的貓就可能認不出來。資料增強是在不多拍照片的情況下，人工製造這些變化，逼模型去學真正重要的特徵（耳朵形狀、毛的紋理），而不是背下角度和亮度。

怎麼運作

常見的增強分成兩類：

  • 幾何變換：水平翻轉、隨機裁切、旋轉、縮放。改變像素的位置。
  • 色彩變換：調亮度、對比、飽和度，加雜訊。改變像素的數值。

重點是「隨機」與「每次都不同」：每一輪（epoch）讀到同一張圖時，套用的變化都是重新抽的，所以模型幾乎不會看到兩次一模一樣的輸入。增強只在訓練時做，測試時用原圖。

# 三種最基本的增強
import numpy as np

a = np.array([[ 30,  80, 120],
              [ 60, 200, 240],
              [ 10,  90, 250]], dtype=np.uint8)

flipped = a[:, ::-1]                       # 水平翻轉：每列左右顛倒

# 調亮：先轉成 int 避免溢位，再截到 0–255
brighter = np.clip(a.astype(int) + 50, 0, 255).astype(np.uint8)

crop = a[0:2, 1:3]                         # 裁切出右上 2×2

print(flipped[0])    # [120  80  30]
print(brighter[1])   # [110 250 255]
print(crop)          # [[ 80 120] [200 240]]

注意亮度 +50 那張：240 + 50 = 290、250 + 50 = 300，都超過上限，只能停在 255。原本 240 和 250 的差別不見了，這就是調亮過頭會「過曝」的原因。如果沒有先轉成 int，uint8 會直接溢位，290 變成 34，亮的地方反而變暗。

常見誤解

  • 增強越多、越誇張越好。增強必須保留答案不變。辨識數字時把 6 上下翻轉就變成 9，標籤就錯了；醫學影像左右翻轉可能讓器官位置不合理。要選「真實世界會出現」的變化。
  • 資料增強是先把資料集變成十倍大再存起來。通常是在讀資料的當下即時隨機產生，不另外存檔。這樣每一輪看到的版本都不同，變化的組合幾乎是無限的。
  • 測試時也要做增強，才能跟訓練一致。一般測試用原圖。有一種技巧叫測試時增強（TTA），是把多個增強版本的預測取平均，但那是刻意的額外步驟，不是預設做法。
