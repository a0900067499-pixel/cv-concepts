卷積

Convolution

一句話定義

拿一個小小的數字視窗，在影像上一格一格滑過去，每到一個位置就把底下的像素乘上視窗裡的數字再加總，得到一張新的圖。

直覺理解

像拿一個特定形狀的印章在紙上到處比對：哪裡的圖案跟印章越像，那裡就印得越深。印章換成「左暗右亮」的形狀，就會在每個由暗轉亮的地方留下深色印子。

那個小視窗叫做卷積核（kernel，也叫 filter）。核裡的數字決定它在找什麼：找邊緣、找斑點、還是把影像弄模糊。卷積神經網路厲害的地方在於，這些數字不是人設定的，而是從資料裡學出來的。

怎麼運作

以 3 × 3 的核為例，每個輸出位置 (i, j) 的值，是輸入影像以 (i, j) 為左上角的 3 × 3 區塊，和核逐格相乘後的總和：

out[i, j] = Σm=0..2 Σn=0..2 img[i+m, j+n] × k[m, n]

核每次往右移一格，到底後換下一列。5 × 5 的輸入用 3 × 3 的核、不補邊，輸出會變成 3 × 3，因為核只能放在 3 × 3 個位置上。一般公式是：輸出邊長 = 輸入邊長 − 核邊長 + 1。

# 手寫一個最簡單的 2D 卷積（不補邊、步幅 1）
import numpy as np

img = np.array([[10, 10, 10, 200, 200]] * 5)   # 左暗右亮的 5×5 圖
k = np.array([[-1, 0, 1],
              [-1, 0, 1],
              [-1, 0, 1]])                       # 垂直邊緣核

H, W = img.shape
kh, kw = k.shape
out = np.zeros((H - kh + 1, W - kw + 1), dtype=int)

for i in range(out.shape[0]):
    for j in range(out.shape[1]):
        patch = img[i:i + kh, j:j + kw]          # 取出 3×3 區塊
        out[i, j] = (patch * k).sum()            # 逐格相乘再加總

print(out)
# [[  0 570 570]
#  [  0 570 570]
#  [  0 570 570]]

常見誤解

  • 深度學習裡的卷積，就是數學課教的卷積。數學上的卷積要先把核上下左右翻轉，深度學習框架其實都沒翻，嚴格說是「互相關」（cross-correlation）。因為核是學出來的，翻不翻結果都一樣，所以大家沿用了卷積這個名字。
  • 一個卷積層只有一個核。一層通常有幾十到幾百個核，每個核產生一張輸出圖（特徵圖）。而且輸入是彩色時，每個核的形狀其實是 3 × 3 × 3，會同時看 RGB 三個通道。
  • 卷積之後影像一定會變小。只要在周圍補一圈 0（padding），3 × 3 的核就能讓輸出和輸入一樣大。大多數網路都會這樣做。
